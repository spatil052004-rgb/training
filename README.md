# Bash Calculator

This project is a simple calculator created using Bash scripts.

## Steps Completed

1. Created a new GitHub repository.
2. Opened the repository in GitHub Codespaces.
3. Created separate branches for addition, subtraction, multiplication, and division.
4. Created separate Bash scripts for each operation.
5. Tested each script in the terminal.
6. Added and committed each script using Git.
7. Pushed each branch to GitHub.
8. Created a separate Pull Request for each operation.
9. Merged the Pull Requests into the main branch.

## Calculator Files

- `addition.sh`
- `subtraction.sh`
- `multiplication.sh`
- `division.sh`
